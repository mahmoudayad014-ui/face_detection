# 👤 Face Detection with Python & OpenCV

A simple real-time Face Detection project built with **Python** and **OpenCV**.

The project uses the computer's webcam to detect human faces in real time and displays a rectangle around each detected face.

---

## 🚀 Project Overview

This project demonstrates how to build a basic real-time computer vision application using OpenCV.

The application:

- 📷 Accesses the webcam
- 🖼️ Captures video frames in real time
- 🔄 Converts frames to grayscale
- 👤 Detects human faces using Haar Cascade
- 🟩 Draws a rectangle around detected faces
- 🔢 Displays the number of detected faces
- ⌨️ Allows the user to exit by pressing `Q`

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- Computer Vision
- Webcam
